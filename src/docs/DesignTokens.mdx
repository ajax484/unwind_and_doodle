# Design Tokens

<Subtitle>Curated color scales, typography rules, border radii, and elevation levels powering Unwind & Doodle.</Subtitle>

Design tokens are the visual atoms of our design system. In code, they are configured in `src/app/globals.css` via the Tailwind CSS `@theme` directive and exposed through utility classes.

## ✍️ Typography Tokens

Our design system uses two distinct typefaces:

| Token | CSS Variable | Font Family | Usage |
| :--- | :--- | :--- | :--- |
| **`font-heading`** | `--font-heading` | `'Fredoka', cursive, sans-serif` | Brand titles, card headings, section headers, badges |
| **`font-body`** | `--font-body` | `'Plus Jakarta Sans', sans-serif` | Body text, captions, buttons, forms, tables |

---

## 🔘 Corner Radius Tokens

Radius values create consistent, friendly, and tactile rounded geometry.

| Token | Class | Pixel Value | Application |
| :--- | :--- | :--- | :--- |
| **Small** | `rounded-lg` | `8px` | Badges, tags, form input controls |
| **Medium** | `rounded-xl` | `12px` | Buttons, navigation links, alert cards |
| **Large** | `rounded-2xl` | `16px` | Product cards, modals, popovers |
| **Pill / Circle** | `rounded-full` | `9999px` | Avatars, steppers, cart badges, filter chips |
